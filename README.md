## 🚀 Funcionalidades

- 📱 **Design Mobile-First:** Interface 100% responsiva adaptada para smartphones, tablets e desktops.
- 🍨 **Cardápio Digital Dinâmico:** Apresentação de opções populares, combinações especiais e tamanhos.
- 🛒 **Modal Interativo de Pedido:** Sistema de simulação com seleção de adicionais e cálculo de subtotal em tempo real via JavaScript.
- 🎨 **Visual Moderno (Food Tech):** Header translúcido (*glassmorphism*), paleta de cores temática e microinterações suaves.
- ⚡ **Alta Performance:** Construído exclusivamente em HTML, CSS e JS Vanilla, garantindo carregamento ultrarrápido sem dependências externas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico:** Estruturação acessível e otimizada para SEO.
- **CSS3 Moderno:** Flexbox, CSS Grid, variáveis nativas (`CSS Custom Properties`) e efeitos de *glassmorphism*.
- **JavaScript Vanilla:** Manipulação de DOM, controle de eventos e lógica de abertura/fechamento de modal.
- **GitHub Pages:** Hospedagem e deploy contínuo da aplicação.
